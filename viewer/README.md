# Page-turning proof viewer

Open `index.html` through a local web server, then use the arrow buttons or
your keyboard's left and right arrows to turn pages. The viewer intentionally
uses rendered proof images, so it opens immediately without a third-party
viewer service or a network dependency.

The print source remains `../output/pdf/nowheres-end-print-edition.pdf`. Its
20 reader-order pages are rendered at 150 ppi in `pages/` for smooth browser
preview; use the PDF, not these PNGs, for printing.
