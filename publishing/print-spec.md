# Print specification — US Letter saddle stitch

## Finished object

| Property | Specification |
|---|---|
| Trim size | 8.5 × 11 in (US Letter), portrait |
| Binding | Saddle stitch: folded sheets, two staples on spine |
| Page count | Multiples of 4; current target: 24 pages including covers |
| Stock | Cover: 80–100 lb text / 65–80 lb cover; interior: 60–70 lb text |
| Printing | Full color cover; interior black plus one spot green, or full color |
| Bleed | 0.125 in on every edge for art or color touching trim |
| Safe area | Keep live text 0.375 in from trim and 0.50 in from spine |
| Images | 300 ppi at placed size; CMYK for commercial offset printing |

## Interior grid

- Set the main text on a single, generous column—this is a module, not a
  digest. Use sidebars only for boxed text, wandering events, and rules.
- Recommended live-text margins: 0.625 in outer, 0.75 in inner, 0.625 in top,
  0.70 in bottom. Add a 0.125 in gutter allowance for interior facing pages.
- Put page numbers at the outer bottom corner. Do not number the front cover;
  the inside cover may be unnumbered or use a discreet folio.
- Use two visual layers: a readable serif body face and a sharp display face
  for section heads. Avoid faux distressed fonts below 12 pt.
- A quiet green accent, moth motif, and occasional crimson callout connect the
  product-inspired Green Hour material without reproducing existing trade dress.

## Saddle-stitch rules

1. The finished page count must be divisible by four. Add notes, a reference
   page, or intentionally blank pages instead of padding at random.
2. Supply reader-order pages to a printer unless it specifically requests an
   imposed file. Printing software performs imposition.
3. If hand-printing, use `publishing/imposition-20pp.md` to pair pages. Print
   duplex with short-edge flip, then fold, collate, and staple on the fold.
4. Expect small *creep* (inner sheets extend farther). It is negligible at 24
   pages but should be compensated by the printer for a thicker edition.

## Required files for a printer

- A press-ready PDF/X-4 (ask the printer for its preferred standard).
- All bleeds and crop marks only if requested.
- Fonts embedded; images flattened only if the printer requires it.
- A proof examined at actual size before placing a production order.
