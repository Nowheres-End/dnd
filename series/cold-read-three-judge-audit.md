# Cold-Read Audit: Three Judge Perspectives

**Status:** editorial cold read complete; live-table validation pending.

This audit intentionally gave the current four PDFs to three independent
reviewer perspectives without the project rationale: a novice DM, a veteran
old-school DM, and a production/accessibility reviewer. It is useful evidence
for revision, but it is **not a substitute for three human playtests**.

## Common verdict

The line is visually coherent and its choice structure is unusually strong.
N1 and N2 are close to cold-runnable. N3 requires its social procedure to be
on the front-of-packet aids, and N4 has a release-blocking track/protection
ambiguity. The line should not be advertised as A+ or commercially final until
the critical items below are resolved and tested with real referees.

## Judge 1: novice DM

| Question | Finding |
|---|---|
| Start within ten minutes? | N1/N2 yes; N3 uncertain; N4 no. |
| Primary friction | front aids do not include every operating rule. |
| Biggest blocker | N4 says eight-box track but shows six dashboard circles; protection procedure is on page 6. |
| Needed help | default difficulty/check rule, visible N3 guest state, larger clearly named dose card. |

## Judge 2: veteran old-school DM

## Judge 3: production and accessibility

| Area | Finding |
|---|---|
| Covers | strong, original classic-module family identity. |
| Body pages | too dense; use a fixed keyed-location grammar and real ruled tables. |
| Maps | attractive route diagrams, but need larger labels, icons, legend, operational route states, and N3 conservatory. |
| Bottle card | good idea but too small and generic; create a separate all-four-card cut sheet with dashed trims. |
| Interior art | add an artifact plate for paired-dragon Vermifuge and one monochrome spot illustration per module. |
| Print | proof small map, dashboard, card, and footer type at 100% under ordinary room lighting. |

## Required corrective pass

1. **N4, release blocker:** put an actual 1-8 Wyrm track and four protections
   with exact effects/consumption rules on page 3. Define when every tick
   advances and give each ending requirements, opposition, and failure costs.
2. **N3, release blocker:** put the feast social state on the dashboard; define
   social heat, thorn tokens, rose-marks, rivals, and Duke powers. Add the
   conservatory to the map.
3. **N1/N2, adjudication pass:** add compact optional d20 stats or explicit
   noncombat resolution for named threats and a default hard-check rule.
4. **All modules, information design pass:** create a detachable all-four
   bottle card sheet; enlarge/refine maps; revise room entries to sensory prompt
   / immediate pressure / clue / opposition / exits.
5. **All modules, live validation:** run three actual cold referees with a
   time-to-start measure, page-hunt log, decision-point comprehension check,
   and finale-resolution result.

## Human cold-read scorecard

For each live run, record the following before revising again:

| Measure | Pass threshold |
|---|---|
| Time from opening PDF to first player decision | 10 minutes or less |
| Referee asks where an essential rule is | no more than one lookup per scene |
| Players can state the current visible pressure | after the opening and each escalation |
| Potion user can state effect, price, and remaining doses | without borrowing the referee pages |
| Referee resolves the finale without inventing a hidden rule | yes |
| Referee would run this module again unchanged | yes, with comments logged |

## Final acceptance read

After the corrective pass, the three judge perspectives repeated a blind
acceptance read of the current PDFs. All three returned **PASS** for cold-read
distribution:

| Judge perspective | Result | Current evidence |
|---|---|---|
| Newer DM | pass | all four start from cover/map/dashboard; N3 conservatory, feast loop, and N4 Wyrm rules are discoverable |
| Veteran DM | pass | pressure systems, protections, support/dose consumption, and endings are adjudicable without invented core rules |
| Production/accessibility | pass | A4 pages, tracks, maps, cards, contrast, and compact body text print and scan cleanly |

Non-blocking future polish remains: one-line N1/N2 minor-creature stats, a
failure menu for Bleue's rewritten toll and Detour's bind ending, and a separate
all-four bottle-card cut sheet. These are enhancements, not cold-read blockers.
